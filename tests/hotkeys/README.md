# 문항 이동 포커스 검증

`node tests/hotkeys/browser.cjs` — Playwright 패키지와 로컬 Chrome이 필요하다.
공용 Playwright 설치를 사용하면 `NODE_PATH`로 지정한다.

실제 hotkeys/checkpoint를 가상 편집기·상태 이벤트와 함께 실행한다. MAIN 브리지와
Angular 자체를 재현한 통합 검사는 아니며 실제 지원서에 입력·저장하지 않는다.

- 아무 입력/Tab/클릭 없이 Alt+1 → 2 → 3 → 1 → 3 → 2를 연속 실행한다.
- 포커스된 답변란을 상태 이벤트 이후 45ms에 교체하거나 잠시 숨기는 경우,
  동일 textarea를 재사용하는 경우의 실제 포커스와 검수 캐럿 표시를 확인한다.
- Alt+위/아래, 빠른 연속 요청의 최종 문항, 클릭/Esc 취소, 즉시 이어 쓰기와 저장 미호출을 확인한다.
- `JSL_FOCUS_BASELINE=1`이면 HEAD의 수정 전 checkpoint로 실행한다.
