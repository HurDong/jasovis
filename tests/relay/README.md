# 자비스 호출 검증

```sh
node --test tests/relay/source.test.cjs
node --test tests/relay/profile.test.cjs
node tests/relay/browser.cjs
```

복사 패널은 `src/features/relay-source.js`, `src/features/relay-panel.js`와
`src/core/gpt-background.js`의 `relay:` 메시지 경로를 사용한다.
개인 이력 계약은 `src/core/relay-profile.js`, 편집 UI는 `src/features/relay-panel.js`(패널 안)를 사용한다. 옵션 화면에는 편집기가 없다.
브라우저 검사는 Playwright/Chromium이 필요하다. 공용 설치 사용 시 `NODE_PATH`를 해당 환경에 맞춘다.

## 내 이력 — 2026-09-12

- `profile.test.cjs`: 빈 초기 상태, 등록번호의 앞자리 0·날짜 정밀도·공백/줄바꿈 보존,
  손상된 저장값/버전/분류/숫자형 값/용량 초과 거절, 추가 메타데이터 제외를 검증한다.
  붙여넣기 병합의 원문 보존·중복/같은 이름 건너뛰기·오류 시 편집본 불변·분류별 50개 한도도 검증한다.
- `browser.cjs`: 임시 프로필에 실제 MV3 확장을 로드하고 가상 페이지/이력만 사용한다.
  옵션 화면에 편집 UI·입력칸이 없음, 빈 분류에서 **+ 분류 추가**, 어학 외국어 활용능력 틀, 첫 칸 필수,
  패널 입력 키가 사이트 `document` keydown 리스너에 도달하지 않음, ✎ 칸 수정의 Esc 취소·Enter/✓ 저장·첫 칸 비우기 거절,
  다른 탭이 먼저 바꾼 항목의 저장 거절과 다시 그려도 남는 입력값, 여러 줄 칸의 Enter 줄바꿈·Ctrl+Enter 추가, 삭제 확인/취소,
  JSON의 빈 입력·예시 틀·필드 오류·잘못된 JSON 알림과 입력 시 알림 해제, 저장 전 미리보기(추가 개수·제목·같은 항목·이름 충돌),
  미리보기의 HTML 비실행, 추가하고 저장 뒤 분류 이동, 새 항목이 없을 때 닫기를 확인한다.
- 패널에서는 기존 문항·개별 필드의 실제 클립보드 복사, 두 줄 미리보기와 전체 원문,
  번호로 항목 고르기와 항목별 진행 기억, 하단 고정 영역의 값·버튼 문구와 복사 후에도 같은 버튼 위치,
  복사하고 다음·아무 칸에서 이어가기·빈 값 건너뛰기·마지막 칸 뒤 다음 항목으로 넘어가기(마지막 항목이면 앞의 미완료 항목)·처음부터 다시·모두 복사한 번호 표시,
  한 분류씩 펼치기, 빈 값 비활성화, HTML 문자열의 비실행, 가상 사이트 초안 보존,
  칸 수정 뒤에도 이어지는 복사 진행, 1280/375/320px 화면 경계(복사·JSON·새 항목 화면), 다른 탭 저장의 패널 반영, 전체 닫기 후 개인정보 보존을 확인한다.
  Windows 클립보드 읽기에서 LF→CRLF 변환은 줄바꿈 종류만 정규화하고 공백·빈 줄·본문은 대조한다.
- 변경 후 위 자동 검사와 가상 데이터의 MV3 브라우저 검사를 통과했다. `JSL_RELAY_SCREENSHOT`을
  저장소 밖 경로로 지정하면 마지막 패널 화면을 저장한다. 테스트 결과는 실사용 프로필 등록/실사이트 저장 검증이 아니다.
- 적용은 확장 다시 로드 후 자소설/복사 패널 탭을 새로고침한다. 입력 중인 초안은 먼저 보존한다.
  필요하면 기존 호출을 닫았다가 다시 호출한다. 패널에서 분류를 열고 **+**·✎·**JSON으로 추가**로 편집한다.
  실제 개인정보는 자동 테스트나 배포 파일에 포함하지 않는다.

## 명칭과 닫기 흐름

1. 자소서 대시보드에 **자비스 호출**이 표시되는지 확인한다.
2. 호출하면 같은 자소서의 버튼이 **자비스 닫기**로 바뀌는지 확인한다.
3. 패널의 ✕ 안내와 접근성 이름이 **모든 탭에서 닫기**인지 확인한다.
4. ✕로 닫은 뒤 대시보드가 **자비스 호출**로 돌아오는지 확인한다.
5. 다시 호출한 뒤 대시보드의 **자비스 닫기**로도 패널이 사라지는지 확인한다.
6. 최초 권한 설정 화면의 제목과 돌아갈 버튼 안내가 **자비스 호출**인지 확인한다.

확장 동작 전체를 확인할 때에는 기존 탭·새 탭 표시, 다른 자소서로 전환,
번호 클릭의 답변 전체 복사와 줄바꿈 보존, ✕로 모든 탭에서 닫기를 함께 확인한다.
로컬 검증에서는 가상 문항·답변을 사용한다. 실제 지원서의 입력·저장·제출은 별도 범위다.

## 검증 기록 — 2026-09-11

- 사용자가 명칭 변경 전 확장 리로드 후 문항 전환 커서와 복사 바가 정상이라고 확인했다.
- 명칭 변경 후 실제 기능 파일을 가상 JSL·Chrome storage/runtime API에 연결한 로컬
  브라우저 화면에서 위 1~6번을 확인했다. 실제 확장 권한·다중 탭 전파 검증은 아니다.
- 변경한 두 JavaScript 파일의 `node --check`와 `git diff --check`를 통과했다.
- 변경 후 실제 Chrome 확장 화면은 **미검증**이다. 확장을 리로드하고 자소서 탭을
  새로고침해야 한다. 이미 열린 외부 탭에 남은 이전 패널도 새로고침 후 확인한다.
- 명칭 변경 당시 긴 문항 말풍선 축약은 시안 선택 전이라 포함하지 않았다.

## 두 줄 말풍선 — 2번 시안 선택 후

- 긴 질문·줄바꿈·공백이 포함된 가상 문항: 폭 230px, 글자 영역 최대 두 줄,
  넘치는 부분의 말줄임과 글자 수·복사 안내 제거를 로컬 브라우저에서 확인했다.
- 긴 URL만 있는 문항도 두 줄 안에서 줄바꿈·말줄임되며 텍스트가 밖으로 새지 않았다.
  짧은 문항은 한 줄로 표시됐다. 패널 본체는 폭 48px을 유지했다.
- 번호 클릭 후 `복사됨`만 담긴 작은 말풍선이 표시됐다. 가상 clipboard API에 전달된
  답변을 전체 원문과 대조해 앞뒤 공백·빈 줄·줄바꿈이 보존됨을 확인했다.
- `node --check src/features/relay-panel.js`, `git diff --check`를 통과했다.
- 실제 확장 클립보드 권한과 변경 후 실사이트 동작은 미검증이다.
