# 자비스 호출 검증

```sh
node --test tests/relay/source.test.cjs
```

복사 패널은 `src/features/relay-source.js`, `src/features/relay-panel.js`와
`src/core/gpt-background.js`의 `relay:` 메시지 경로를 사용한다.

## 명칭과 닫기 흐름

1. 자소서 대시보드에 **자비스 호출**이 표시되는지 확인한다.
2. 호출하면 같은 자소서의 버튼이 **자비스 닫기**로 바뀌는지 확인한다.
3. 패널의 ✕ 안내와 접근성 이름이 **모든 탭에서 닫기**인지 확인한다.
4. ✕로 닫은 뒤 대시보드가 **자비스 호출**로 돌아오는지 확인한다.
5. 다시 호출한 뒤 대시보드의 **자비스 닫기**로도 패널이 사라지는지 확인한다.
6. 최초 권한 설정 화면의 제목과 돌아갈 버튼 안내가 **자비스 호출**인지 확인한다.

확장 동작 전체를 확인할 때에는 기존 탭·새 탭 표시, 다른 자소서로 전환,
번호 클릭의 답변 전체 복사와 줄바꿈 보존, ✕로 모든 탭에서 닫기를 함께 확인한다.
로컬 검증에서는 가상 문항·답변을 사용한다. 실제 지원서의 입력·저장·제출은 별도 범위다.

## 검증 기록 — 2026-09-11

- 사용자가 명칭 변경 전 확장 리로드 후 문항 전환 커서와 복사 바가 정상이라고 확인했다.
- 명칭 변경 후 실제 기능 파일을 가상 JSL·Chrome storage/runtime API에 연결한 로컬
  브라우저 화면에서 위 1~6번을 확인했다. 실제 확장 권한·다중 탭 전파 검증은 아니다.
- 변경한 두 JavaScript 파일의 `node --check`와 `git diff --check`를 통과했다.
- 변경 후 실제 Chrome 확장 화면은 **미검증**이다. 확장을 리로드하고 자소서 탭을
  새로고침해야 한다. 이미 열린 외부 탭에 남은 이전 패널도 새로고침 후 확인한다.
- 명칭 변경 당시 긴 문항 말풍선 축약은 시안 선택 전이라 포함하지 않았다.

## 두 줄 말풍선 — 2번 시안 선택 후

- 긴 질문·줄바꿈·공백이 포함된 가상 문항: 폭 230px, 글자 영역 최대 두 줄,
  넘치는 부분의 말줄임과 글자 수·복사 안내 제거를 로컬 브라우저에서 확인했다.
- 긴 URL만 있는 문항도 두 줄 안에서 줄바꿈·말줄임되며 텍스트가 밖으로 새지 않았다.
  짧은 문항은 한 줄로 표시됐다. 패널 본체는 폭 48px을 유지했다.
- 번호 클릭 후 `복사됨`만 담긴 작은 말풍선이 표시됐다. 가상 clipboard API에 전달된
  답변을 전체 원문과 대조해 앞뒤 공백·빈 줄·줄바꿈이 보존됨을 확인했다.
- `node --check src/features/relay-panel.js`, `git diff --check`를 통과했다.
- 실제 확장 클립보드 권한과 변경 후 실사이트 동작은 미검증이다.

## 구릿빛 워프 버튼 — 4번 시안 선택 후

- `source.test.cjs` 자동 테스트 4개: 호버 시 워프 그리기와 라벨·캔버스 보존,
  호출·닫기 메시지 경로, 숨김·화면 밖·DOM 분리 시 중단과 재개,
  모션 감소 설정 변경, Canvas 미지원 시 기본 기능 유지를 확인한다.
- 실제 `relay-source.js`를 가상 JSL/storage/runtime API와 연결한 로컬 브라우저에서
  버튼 높이 38px, 구릿빛 워프 렌더, 호출 후 캔버스 유지, 패널 ✕로 닫은 뒤
  라벨 복귀를 확인했다. 브라우저 콘솔 오류·경고는 없었다.
- `node --check src/features/relay-source.js`, `git diff --check`를 통과했다.
- 변경 후 실제 자소설 대시보드는 미검증이다. 확장 리로드 후 자소설 탭 새로고침이 필요하다.

## 차콜 패널 — 1번 대비 시안 선택 후

- 로컬 브라우저의 흰 화면에서 실제 패널 코드로 차콜 배경·밝은 번호·복사 후 회색 번호를 확인했다.
- 폭 48px, 두 줄 흰 말풍선, 답변 전체의 공백·줄바꿈 보존을 확인했다.
- 호출 버튼 자동 테스트 4개와 패널 JavaScript 문법 검사, `git diff --check`를 통과했다.
- 변경 후 실사이트는 미검증이다. 확장 리로드 후 패널이 열린 외부 탭도 새로고침해야 한다.
