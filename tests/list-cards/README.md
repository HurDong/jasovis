# 작성 중 카드 경계 검증

2026-09-11, 사용자 선택 3번(왼쪽 회색 경계 띠)을 반영했다.

- 실제 `list-design.css`를 가상 카드 화면에 적용해 일반 작성 중 카드의 회색 4px 띠,
  `#ccc` 외곽선, 왼쪽 여백 16px을 확인했다.
- `data-jsl-urgent` 및 `.end-time.soon` 두 임박 경로 모두 기존 주황 배경·띠를 유지했다.
- 진행률 코드가 주입하는 `padding-left:12px !important` 규칙이 함께 있어도 16px 여백이 적용됐다.
- 변경 전후 동일한 한 줄 가상 카드의 높이 64.5px이 일치했다. 제출 완료 카드의
  높이·색·띠·여백도 동일했다. 긴 제목의 줄바꿈 높이는 내용과 화면 폭에 따라 달라질 수 있다.
- `git diff --check`를 통과했다. CSS 변경이며 새 자동 테스트는 추가하지 않았다.
- 변경 후 실사이트·실제 드래그는 미검증이다. 확장 리로드 후 목록 탭을 새로고침하고
  일반/임박 카드 구분과 기존 드래그를 확인한다. 스크롤 높이 계산은 변경하지 않았다.
