# 채팅 도구 검증

실제 계정·채팅 내용 없이 확장 코드 그대로 연결한 가상 데이터 화면이다.

```sh
node --test tests/chat-tools/main.test.cjs
node tests/chat-tools/serve.cjs
```

서버가 출력한 로컬 주소 `/`는 React, `/angular`는 Angular 재현 화면이다.
브라우저에서 다음 흐름을 확인한다.

- 내 메시지만 표시, 내용 검색, 날짜·삭제 메시지, 항목에서 원래 대화 위치 이동.
- 이전 메시지 추가 로딩, 중단, 로딩 정체 안내, Escape와 기존 스크롤 위치 복원.
- 패널 열기·닫기 전후 입력 중인 가상 초안 보존.
- 빠른 이동의 28개 방·검색·현재 방·읽지 않은 수·긴 제목과 실제 방 전환.
- 헤더 재생성 시 중복 버튼 없음, 외부 방 전환 시 기존 목록 닫기.
- 구조 변경 오류와 실제 0개인 빈 목록 구분, 300px 좁은 창에서 가로 넘침 없음.
- `모의 창 전환`은 문서 숨김·복귀 이벤트를 재현한다. 검색어·패널·목록 위치 유지,
  탐색 중일 때는 탐색만 중단되는지 확인한다. 실제 OS Alt+Tab 검증과 구분한다.

이 화면은 사이트의 저장소 메서드·메시지 행·스크롤 로더를 재현한다. 실제 서버 응답이나
향후 사이트 배포와의 호환을 증명하지는 않는다. 공개 클라이언트의 저장소 모듈 지문과
실제 확장 주입 여부는 별도로 확인한다.

## 답글 원본 이동 회귀 검사

Playwright와 Chrome이 있는 환경에서 `node tests/chat-tools/reply.browser.cjs`를 실행한다.
실제 MAIN/UI 스크립트에 가상 DOM·React props·Angular 응답을 연결한다.

- 다른 영역의 선택이 있어도 이동하며, 인용문 선택은 복사할 수 있다.
- 조회 및 지연된 원본 표시 중 동일 ID 답글 행이 교체돼도 이동·복귀한다.
- 입력 중인 초안 보존, 원본 ID 변조 및 취소 후 이동 거절을 확인한다.

`JSL_REPLY_BASELINE=1`은 비교 기준 커밋 `5a44033`의 스크립트를 사용한다.
`JSL_REPLY_CASE=replacement`를 함께 지정하면 선택 영역 검사를 건너뛰고 행 교체를 재현한다.
지연 로딩은 가상 타이머이며 실제 서버 과거 메시지 응답을 검증하는 테스트가 아니다.
