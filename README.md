# 자비스 for 자소설닷컴

자소설닷컴(jasoseol.com)의 자기소개서 작성·전형 목록 관리·채팅 이용을 돕는 Chrome 확장 프로그램(MV3).

> **비공식 프로젝트입니다.** 자소설닷컴 운영사(주식회사 리멤버앤컴퍼니)와 무관한 개인 프로젝트이며,
> 운영사의 허가·후원·검수를 받지 않았습니다. 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.

개발자가 운영하는 별도 수집 서버는 없습니다. 답변 뱅크·사용자 설정 등 확장이 보관하는 데이터는
브라우저 로컬(`chrome.storage.local`)에 저장합니다. 공고·자소서·채팅 조회와 사이트 저장·정렬 기능은
사용자의 기존 로그인 상태로 자소설닷컴 서버와 통신합니다 → [PRIVACY.md](PRIVACY.md)

## 기능

**자소서 편집 페이지** (`/resume/:id`)

| 기능 | 설명 |
|---|---|
| 대시보드 위젯 | 문항별 상태(미작성/작성중/완료)·글자수·진행 게이지를 플로팅 카드로. 드래그 이동, 접기, 위치 기억 |
| 검수 위치 마커 | 캐럿이 있는 문장을 하이라이트. 문항별 마지막 위치를 기억하고, `Tab`으로 문장 단위 이동 |
| 복사 | 활성 문항 평문 복사 / 기업·문항·글자수까지 붙은 전체 복사(LLM 프롬프트용) |
| 붙여넣기 | 문항 카드에서 클립보드 본문을 바로 입력. 다른 문항으로 전환할 필요 없이 사용하며, 기존 답변을 덮어쓰면 적용·되돌리기 제공 |
| 자동 맞춤법검사 | 붙여넣기를 감지해 사이트 내장 맞춤법검사를 자동 실행 + 글자수 초과 경고 |
| 단축키 | 문항 전환·복사·저장·검사·문장 이동 (아래 표) |
| 답변 뱅크 | 작성한 문항·답변을 로컬에 자동 아카이브. 확장 팝업에서 검색·복사·삭제 |
| JD 패널 | 이력서와 연결된 채용공고를 화면 왼쪽 여백에 배경처럼 띄움 |

**자소서 목록 페이지** (`/resume_list`)

| 기능 | 설명 |
|---|---|
| 반응형 전형 보드 | 모든 전형 구역을 가로 스크롤 없이 배치. 작성 중·제출 완료는 위아래로 나누어 독립 스크롤하며, 좁은 창에서는 왼쪽 카드를 한 열로 표시 |
| 상태 구분 | 작성 중·제출 완료 제목 색, 전형 단계 표시, 합격·불합격 배지와 빈 상태 카드. 제출 완료 카드는 마감일을 숨기고 긴 제목을 말줄임 |
| 문항 진행률 | '작성 중' 카드에 작성한 문항 수와 작은 진행 막대 표시 |
| 전형 통계 | 서류/1차/2차/최종 단계별 통과율과 발표 대기·지원 수. 정렬 버튼 옆에 배치하고 공간이 부족하면 다음 줄로 이동 |
| 카드 우클릭 | 자소서 편집·새 탭에서 편집, 해당 공고 본문 모달, 채팅방 이동, 공고 링크·자기소개서 내용 복사 |
| 정렬 자동 교정 | 지원하는 정렬 기준에서 작성 중 카드의 순서가 어긋난 경우 사이트 정렬 버튼을 대신 실행. 페이지 로드당 최대 한 번이며 결과는 사이트에 저장 |
| 준비 중 공고 담기 | 문항이 아직 열리지 않은 공고를 공고 모달에서 담아 목록에 보관. 목록 방문 시 문항 개설·자소서 작성 여부를 확인 |

**채팅 패널** (자소설닷컴 내 지원되는 채팅 화면)

| 기능 | 설명 |
|---|---|
| 채팅방 공고 | 회사 채팅방의 공고 안내 바를 누르면 공고 목록·본문과 내가 쓴 자소서·전형 결과를 모달로 표시 |
| 답글 원본 이동 | 인용문의 `원본 보기`를 누르면 원본 메시지로 이동·강조. `답글로 돌아가기`로 처음 위치에 복귀 |
| 과거 메시지 탐색 | 원본이 화면에 없으면 사이트의 과거 대화 로딩을 이용해 탐색. 삭제됐거나 탐색 한도 안에 찾지 못한 메시지는 안내 표시 |
| 채팅 테마 | 받은 메시지는 회색, 내 메시지는 브랜드 주황색으로 구분. 답글 인용문·원본 강조·공고 안내 바도 함께 정리 |

답글 이동·테마는 기존 Angular 채팅과 React 채팅 프레임(`/chat-slide`, `/desktop/chat-slide`)을
지원합니다. 사용자가 열람할 수 있는 메시지에만 기존 사이트 기능으로 접근하며, 권한을 우회하지 않습니다.
모든 과거 메시지로의 이동을 보장하지 않으며, 사이트 구조나 로딩 상태에 따라 기능이 제한될 수 있습니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Alt` + `1` ~ `9` | 문항 전환 |
| `Alt` + `C` | 활성 문항 복사 |
| `Alt` + `Shift` + `C` | 전체 복사 |
| `F7` | 맞춤법검사 |
| `Ctrl` + `S` | 저장 |
| `Tab` / `Shift` + `Tab` | 다음 / 이전 문장으로 검수 하이라이트 이동 (답변란 안에서만) |
| `Alt` + `↓` / `Alt` + `↑` | 다음 / 이전 문항으로 전환하고 답변란에 포커스 |
| `Esc` | 답변란 포커스 해제 |
| `Alt` + `/` | 단축키 안내 열기·닫기 |

`Ctrl`+숫자는 크롬 탭 전환이라 가로챌 수 없어서 문항 전환이 `Alt`+숫자입니다.

## 설치 (개발자 모드)

빌드 과정이 없습니다. 저장소를 그대로 로드하면 됩니다.

```bash
git clone https://github.com/HurDong/jasovis.git
```

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 클론한 폴더 선택
4. 열려 있는 자소설닷컴 탭 새로고침 후 편집 페이지·목록·채팅에서 사용

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장의 **새로고침** 버튼을 누르고,
자소설닷컴 탭도 새로고침해야 반영됩니다.

## 구조

```
manifest.json          MV3 매니페스트 — 페이지·프레임별 스크립트와 CSS 주입 설정
src/
  core/
    bridge-main.js     MAIN 월드 — Angular 편집기 상태·액션
    list-main.js       MAIN 월드 — Angular 목록 상태·액션
    chat-main.js       MAIN 월드 — Angular 채팅 원본 조회·이동
    chat-react-main.js MAIN 월드 — React 채팅 원본 식별·탐색
    bridge.js          격리 월드 — 편집기·목록 기능용 JSL API
  features/            기능 모듈 및 화면 스타일
    dashboard.js       플로팅 위젯 + JSL.ui 슬롯 API + 토스트
    checkpoint.js      검수 위치 마커 / 문장 단위 이동
    copy.js  paste.js  spellcheck.js  hotkeys.js  bank.js  jd-panel.js
    list-layout.js  list-design.css  list-progress.js  list-stats.js
    list-menu.js  list-sort.js  watch.js
    chat-jd.js  chat-reply.js  chat-design.css
  popup/               답변 뱅크 검색 팝업
assets/                아이콘 · 로고
```

**두 개의 월드.** 콘텐츠 스크립트 격리 월드에서는 페이지의 `angular`에 접근할 수 없습니다.
그래서 편집기·목록·채팅의 MAIN 브리지가 페이지 상태와 사이트 액션을 다루고, 격리 월드와
이벤트로 통신합니다. 편집기·목록 모듈은 `window.JSL` API를 사용하고,
답글 이동은 별도 `JSL_CHAT_REQ/RES` 채널을 사용합니다. React 채팅 프레임에는 전용 어댑터를 주입합니다.

대시보드·공고 모달·우클릭 메뉴 등 별도 UI는 Shadow DOM으로 사이트 스타일과 분리합니다.
목록 레이아웃·진행률·통계·채팅 테마는 기존 DOM에 요소나 범위를 제한한 CSS를 적용합니다.

인터페이스·상태 스키마·이벤트 계약·검증된 DOM 셀렉터의 단일 기준은 **[SPEC.md](SPEC.md)** 입니다.
개발 및 기여 시 해당 문서를 기준으로 합니다.
