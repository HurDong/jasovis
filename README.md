# 자비스 for 자소설닷컴

자소설닷컴(jasoseol.com) 자기소개서 편집 화면에 작성 보조 UI를 얹는 Chrome 확장 프로그램(MV3).

> **비공식 프로젝트입니다.** 자소설닷컴 운영사(주식회사 리멤버앤컴퍼니)와 무관한 개인 프로젝트이며,
> 운영사의 허가·후원·검수를 받지 않았습니다. 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.

외부 서버가 없고 어떤 데이터도 밖으로 나가지 않습니다. 모든 데이터는 브라우저 로컬
(`chrome.storage.local`)에만 저장됩니다 → [PRIVACY.md](PRIVACY.md)

## 기능

**자소서 편집 페이지** (`/resume/:id`)

| 기능 | 설명 |
|---|---|
| 대시보드 위젯 | 문항별 상태(미작성/작성중/완료)·글자수·진행 게이지를 플로팅 카드로. 드래그 이동, 접기, 위치 기억 |
| 검수 위치 마커 | 캐럿이 있는 문장을 하이라이트. 문항별 마지막 위치를 기억하고, `Tab`으로 문장 단위 이동 |
| 복사 | 활성 문항 평문 복사 / 기업·문항·글자수까지 붙은 전체 복사(LLM 프롬프트용) |
| 자동 맞춤법검사 | 붙여넣기를 감지해 사이트 내장 맞춤법검사를 자동 실행 + 글자수 초과 경고 |
| 단축키 | 문항 전환·복사·저장·검사·문장 이동 (아래 표) |
| 답변 뱅크 | 작성한 문항·답변을 로컬에 자동 아카이브. 확장 팝업에서 검색·복사·삭제 |
| JD 패널 | 이력서와 연결된 채용공고를 화면 왼쪽 여백에 배경처럼 띄움 |
| 채팅방 공고 | 오른쪽 채팅에서 회사 방을 열면 그 회사 공고 목록을 모달로. 내가 그 회사에 쓴 자소서와 전형 결과를 같이 보여줌 (채팅 패널이 있는 페이지 어디서나) |

**자소서 목록 페이지** (`/resume_list`)

| 기능 | 설명 |
|---|---|
| 진행 타일 | '작성 중' 카드에 문항 진행도를 카드마다 같은 자리·같은 크기로 표시 |
| 전형 통계 | 서류/1차/2차/최종 단계별 통과율 바 |

## 단축키

| 키 | 동작 |
|---|---|
| `Alt` + `1` ~ `9` | 문항 전환 |
| `Alt` + `C` | 활성 문항 복사 |
| `Alt` + `Shift` + `C` | 전체 복사 |
| `F7` | 맞춤법검사 |
| `Ctrl` + `S` | 저장 |
| `Tab` / `Shift` + `Tab` | 다음 / 이전 문장으로 검수 하이라이트 이동 (답변란 안에서만) |
| `Alt` + `↓` / `Alt` + `↑` | 위와 동일 (별칭) |
| `Esc` | 답변란 포커스 해제 |
| `Alt` + `/` | 단축키 안내 열기·닫기 |

`Ctrl`+숫자는 크롬 탭 전환이라 가로챌 수 없어서 문항 전환이 `Alt`+숫자입니다.

## 설치 (개발자 모드)

빌드 과정이 없습니다. 저장소를 그대로 로드하면 됩니다.

```bash
git clone git@github.com:HurDong/jasovis.git
```

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 클론한 폴더 선택
4. `https://jasoseol.com/resume/...` 편집 페이지 새로고침

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장의 **새로고침** 버튼을 누르고,
자소설닷컴 탭도 새로고침해야 반영됩니다.

## 구조

```
manifest.json          MV3 매니페스트 (content_scripts 순서 = 실행 순서)
src/
  core/
    bridge-main.js     MAIN 월드. 페이지의 AngularJS 스코프에 접근하는 유일한 파일
    bridge.js          격리 월드. 전역 JSL API 정의 — 기능 모듈은 이것만 사용
    list-main.js       MAIN 월드 (목록 페이지 전용)
  features/            기능 모듈 (JSL.register로 등록)
    dashboard.js       플로팅 위젯 + JSL.ui 슬롯 API + 토스트
    checkpoint.js      검수 위치 마커 / 문장 단위 이동
    copy.js  spellcheck.js  hotkeys.js  bank.js  jd-panel.js
    list-progress.js  list-stats.js
  popup/               답변 뱅크 검색 팝업
assets/                아이콘 · 로고
```

**두 개의 월드.** 콘텐츠 스크립트 격리 월드에서는 페이지의 `angular`에 접근할 수 없습니다.
그래서 `bridge-main.js`(MAIN 월드)만 Angular 스코프를 읽고, 격리 월드와는 `CustomEvent`로만
통신합니다. 기능 모듈은 절대 `angular`를 직접 만지지 않고 `window.JSL` API만 사용합니다.

사이트 전역 CSS 오염이 심해서 **주입하는 UI는 전부 Shadow DOM 안에 렌더**합니다.

인터페이스·상태 스키마·이벤트 계약·검증된 DOM 셀렉터의 단일 기준은 **[SPEC.md](SPEC.md)** 입니다.
코드를 고치기 전에 그 문서를 먼저 읽으세요.
